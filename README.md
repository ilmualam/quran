# Al-Quran Online · Ilmu Alam

**Live:** [quran.ilmualam.com](https://quran.ilmualam.com/) · **Publisher:** [The Ilmu Alam](https://www.ilmualam.com/)

A free, fast, installable Al-Quran reader for Malay speakers. All 114 surah (6,236 ayat, 30 juzuk) with Arabic text, Rumi transliteration, Bahasa Melayu translation and verse-by-verse audio from five qari. No account, no tracking, works offline.

The site is a single static page generated by a small Python build. GitHub Pages serves it with no server, database or framework.

---

## How it works

```
tools/ (source)                      build.py                     site root (generated, deployed)
─────────────────────                ─────────                    ───────────────────────────────
page.html, layout.html   ─┐                                  ┌─>  index.html, */index.html, 404.html
pages.py, plans.py       ─┤                                  ├─>  dasar-privasi.html, assets/og/*.jpg
header.html, footer.html  ├─>  templates + data + CSS  ─────┼─>  sw.js, manifest.webmanifest
home.css (+ quran.min.css)│    -> HTML, JSON-LD, SW, maps   ├─>  sitemap.xml, robots.txt, llms.txt
surahs.py, data-surah/*  ─┤                                  ├─>  assets/js/surah-cta.js
qmeta.json, og.py        ─┘                                  └─>  assets/data/terjemahan-ms.json
```

Runtime has no dependencies: `assets/js/quran-home.js` (vanilla JS, ~16 KB) adds search, the reader, audio, sharing and PWA install on top of the pre-rendered HTML. Tool pages also load `assets/js/alat.js` (~17 KB).

Every tool page is complete without JavaScript: `tools/plans.py` renders the default khatam/hafazan schedule into the HTML at build time, and `alat.js` mirrors the same maths line for line, so the script redraws byte-identical HTML (no flash, CLS 0). `tools/test-alat.mjs` checks that equality plus tasbih, search and reader links in a real browser.

Page, juz, sajdah and manzil boundaries (Mushaf Madinah, 604 pages) are in `tools/qmeta.json`, converted from Tanzil data via [quran-meta](https://github.com/quran-center/quran-meta) (MIT).

## Development

Requires only **Python 3.8+**. No packages, no Node.

```bash
git clone https://github.com/ilmualam/quran.git && cd quran
python3 tools/build.py          # regenerate every generated file
python3 -m http.server 8765     # open http://localhost:8765
node tools/test-alat.mjs        # browser tests (needs Playwright; PLAYWRIGHT_PATH=<node_modules dir> if not global)
```

The build prints a one-line report: page size, total ayat (it must be 6,236), whether ads are on, and any surah still missing an article link.

> **Rule:** never hand-edit or merge-resolve the generated files (`index.html`, `sw.js`, etc.). Change the source in `tools/` and rebuild. If two branches conflict in a generated file, take either side and run the build again.

### Common tasks

| Task | Where |
|---|---|
| Change home text, sections or FAQ | `tools/page.html`, FAQ list in `tools/build.py` |
| Change a tool / info page (text, FAQ, schema) | `tools/pages.py` (privacy body: `tools/privacy.html`) |
| Change schedule maths | `tools/plans.py` **and** `assets/js/alat.js`, then run the browser test |
| Tool page styles | `tools/tools.css` (inlined only on non-home pages) |
| Doa, zikir, tajwid content | `tools/ibadah.py` (Quranic text is always read from `data-surah/` by reference) and `tools/pages2.py` |
| Prayer-time maths / towns / zones | `tools/solat.py` **and** the waktu-solat block in `assets/js/alat.js` |
| Official JAKIM timetables | `.github/workflows/solat-data.yml` runs `tools/solat_fetch.py` monthly (or *Actions → Prayer times (JAKIM) → Run workflow*), writes `assets/data/solat/<ZONE>-<YEAR>.json`, rebuilds and commits |
| "Hari ini" freshness | `.github/workflows/daily-refresh.yml` rebuilds the date-dependent pages at 00:07 MYT daily (no data fetch) |
| Masjid & surau lists | `.github/workflows/masjid-data.yml` runs `tools/masjid_fetch.py` monthly (or *Actions → Masjid & surau (OpenStreetMap) → Run workflow*): one Overpass query per state, each place goes to the zone of its nearest town anchor (`ZONEINFO` in `tools/masjid.py`), writes `assets/data/masjid/<ZONE>.json`, rebuilds and commits |
| Masjid zone towns / page text | `ZONEINFO` in `tools/masjid.py` (zone list = `ZONES` in `tools/solat.py`, same 60 zones as bukitbesi/waktu-solat), page text in `tools/pages5.py`, live search in the masjid block of `assets/js/alat.js` |
| Social cards | `tools/og.py` redraws `assets/og/<page>.jpg` when a page's `ogtitle`/`desc` changes |
| Change header / footer links | `tools/header.html`, `tools/footer.html` |
| Change styles | `tools/home.css` (landing), `assets/css/quran.min.css` (reader) |
| Update the "last updated" date | `TODAY` in `tools/build.py` |
| Add or fix a surah article link | `ARTICLES` in `tools/surahs.py` |
| Enable AdSense | `ADS_CLIENT` + `ADS_SLOTS` in `tools/build.py` |

### Enabling AdSense

Set your publisher ID and up to three ad-unit slot IDs at the top of `tools/build.py`, then rebuild:

```python
ADS_CLIENT = "ca-pub-XXXXXXXXXXXXXXXX"
ADS_SLOTS = ["1234567890", "2345678901", "3456789012"]
```

- Slots sit after the surah list, after "Konteks Malaysia" and after the FAQ. Each reserves its height, so ads cause no layout shift.
- The AdSense script loads only after the visitor's first scroll or tap (or 4 seconds), so it never delays LCP.
- The Content Security Policy is relaxed only while ads are enabled.
- Turn on Google's consent message (AdSense → Privacy & messaging) for EEA/UK visitors.

## Article button on ilmualam.com (Blogger)

`assets/js/surah-cta.js` adds a "🎧 Baca & Dengar Surah …" box to each of the 114 surah articles on www.ilmualam.com, linking to that surah in this reader. The build generates it from `ARTICLES`, so it stays in sync. It runs only on matching article URLs and inserts the box before the first subheading, so it doesn't shift what the reader is already looking at.

Install it once in Blogger (**Layout → Add a Gadget → HTML/JavaScript**, or just before `</body>` in the theme):

```html
<script defer src="https://quran.ilmualam.com/assets/js/surah-cta.js"></script>
```

## Deployment

GitHub Pages serves the `main` branch root as-is: `.nojekyll` turns Jekyll off because the Python build already produces the final HTML, sitemap, canonical tags and JSON-LD (Jekyll would only add build time and ignore files it doesn't understand); `CNAME` points it at `quran.ilmualam.com`. Pushing to `main` deploys within about a minute. Each build changes the service worker's version hash, so returning visitors get the new version on their next visit.

## Legacy widgets (do not delete blindly)

`engine/`, `micro/`, `assets/khatam/` and the older files in `assets/js/` and `assets/css/` (`quran-engine*.js`, `quran.v2*.css`, `doa-kerja-js`, `sitemap.js`, …) are not used by quran.ilmualam.com. Older posts on www.ilmualam.com may still load them from this domain, though. Before removing any of them, search the Blogger theme and posts for the filename.
